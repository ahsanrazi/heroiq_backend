Pinecone (vector store)

Key invariants
  • One LLM call per page at index time. Zero LLM calls at query time.
  • Search cards live inside Pinecone metadata — query path needs no extra DB read.
  • Vector IDs are deterministic (page_{id}_chunk_{i}) so re-indexes overwrite cleanly.
  • SHA-256 content hash drives delta updates — unchanged pages cost $0 to re-sync.
  • One Pinecone namespace per tenant: tenant_{uuid} — hard data isolation.
